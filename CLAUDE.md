# Работа с проектом

Self-hosted OIDC SSO на PHP 8.2+ без фреймворка. Код, комментарии, интерфейс,
CHANGELOG и сообщения коммитов — по-русски.

## Принципы

- **Замер вместо мнения.** Прежде чем чинить «шум» или «медленно» — посчитать на
  живых данных; решение — по цифрам (так в 4.94 шум журнала оказался не там,
  где казалось).
- **Каждая правка — со своей проверкой, и проверка доказана мутацией**:
  `tests/mutations.php` ломает правку и ждёт красного. Проверка для мутации —
  перезапускаемый тест (`admin_lists`, `admin_people`, `login_look` …), не
  `admin_smoke`: он не перезапускается на прогнанной базе и «ловит» фаталом.
- **Один механизм** на одну задачу: не заводить второй путь рядом с первым.
- **Необязательность**: пароли, 2FA и подобное настраиваются и по умолчанию
  выключены — никакой обязаловки.
- **Быстро и без лишних щелчков**: действие дольше 30–60 секунд — плохое.
- **Нейтральные имена.** Репозиторий публичный. В коде, тестах, CHANGELOG и
  коммитах — ни названия конкретной установки, ни имени автора, ни доменов,
  адресов серверов и порталов. В формах — плейсхолдеры, в тестах —
  `example.com`, `*.example`, `test.local`.
- Комментарий объясняет **почему** и с какой версии (`v4.92: …`), а не что.

## Проверки

```bash
bash tests/run-all.sh          # вся батарея: сама поднимает SSO на :8710 и RP на :8711
php tests/admin_lists.php      # отдельный тест; часть тестов ждёт сервер на :8710
php tools/i18n_coverage.php    # «не переведено: 0» — переводы в app/Lang/en-*.php
```

- `templates_test`: вертикальные отступы в CSS кратны 4; каждый класс из
  шаблонов объявлен в таблицах стилей.
- Батарея правит файлы на месте (мутации) — пока она идёт, дерево не трогать.
- CI (`.github/workflows/ci.yml`) гоняет батарею на PHP 8.2–8.4 и выносит
  провалы аннотацией прогона: её видно на странице прогона и через открытый API
  `GET /repos/{owner}/{repo}/check-runs/{job_id}/annotations`.

## Выпуск

1. `SSO_VERSION` в `app/bootstrap.php` и запись в `CHANGELOG.md` (что было
   плохо, что стало, какие проверки; нейтрально).
2. Батарея зелёная.
3. Коммит в `main`, тег `vX.Y.Z`, пуш **явно**:
   `git push origin main refs/tags/vX.Y.Z`.
   Никогда `git push --tags`, `--all`, `--mirror`.
4. Тег запускает «Выкладку» (`.github/workflows/deploy.yml`): батарея на
   PHP 8.4 → сборка `build_dist.php` → архив по SSH на сервер → копия,
   наложение, права, миграции, проверка живой установки. Итог — аннотацией
   прогона. Устройство и секреты — `.github/deploy/README.md`.

## Где что

- `app/Controllers`, `app/Core`, `app/Models`, `templates/`, `public/assets/`,
  `migrations/`, `tests/`, `tools/`.
- Карточки объектов в админке: `ClientMap`, `OrgMap`, `UserMap` (разделы), общие

- Компоненты оформления: `.list-card`, `.stat-tile`, `.health-list`,
  `.act-list`, `.table-cards` (карточки на телефоне), полоса `form_actions()`.
